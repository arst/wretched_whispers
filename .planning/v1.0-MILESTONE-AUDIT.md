## Cross-Phase Integration

### Wired (10/12 exports)

All Phase 1 persistence exports consumed by Phase 2. All Phase 01.1 domain design exports consumed by Character and CharacterPlugin. Identity infrastructure wired in Api Program.cs.

### Integration Issues (2 findings)

**1. Missing AddSqliteInfrastructure in Api Program.cs**
- `WretchedWhispers.Api/Program.cs` registers `AddDbContext` and `AddIdentityApiEndpoints` but does NOT call `AddSqliteInfrastructure`
- Repositories, domain services, Dice, and JsonSerializerOptions are absent from the API DI container
- Impact: Phase 3 game endpoints will throw `InvalidOperationException` on service resolution
- Affected: INFR-02, INFR-03
- Severity: Will block Phase 3

**2. Unawaited SaveCampaign in CampaignPlugin.CreateCampaign**
- `CampaignPlugin.cs:31` — `campaignsRepository.SaveCampaign(newCampaign)` called without `await`
- Fire-and-forget write risks silent data loss; any DB exception swallowed
- Additionally, parameterless `SaveCampaign` stores `UserId = ""`, making campaigns invisible to `GetForUser` queries
- Affected: INFR-02, INFR-03
- Severity: Bug (pre-existing from Phase 1, exposed by Phase 2's multi-tenancy contract)
