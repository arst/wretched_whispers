## Critical Integration Gaps

### Gap 1: UserId Erasure During Agent Turns

**Root cause:** `CampaignPlugin` (6 call sites) and `CampaignService` (6 call sites) call `SqliteCampaignsRepository.SaveCampaign(Campaign)` — the single-argument overload. This creates a new `CampaignEntity` with `UserId = string.Empty`. Any campaign modified by the GM agent during a turn loses tenant ownership.

**Impact chain:**
1. User creates session → `SaveCampaign(campaign, userId)` → UserId set correctly
2. User posts action → agent invokes CampaignPlugin → `SaveCampaign(campaign)` → UserId = ""
3. User lists sessions → `GetForUser(userId)` → modified campaign missing
4. User tries to resume → 404

**Affected:** INFR-03, SESS-02, SESS-03, SESS-04

**Fix options:**
- (a) Make `SaveCampaign(Campaign)` preserve existing UserId via read-modify-write
- (b) Remove the no-userId overload; all saves require userId
- (c) Pass userId through SK agent context so plugins use the userId-aware overload

### Gap 2: No Database.Migrate() in Web API

**Root cause:** `WretchedWhispers.Api/Program.cs` has no migration call. Console apps have it; API does not.

**Impact:** Production SQLite database will not be created on first launch. Every query returns 500.

**Affected:** INFR-02

**Fix:** Add `Database.Migrate()` after `builder.Build()` in Program.cs.
