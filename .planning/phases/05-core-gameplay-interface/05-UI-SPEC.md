# Phase 05 -- UI Design Contract

> Visual and interaction contract for the core gameplay interface. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (manual Tailwind v4) |
| Preset | not applicable |
| Component library | none (hand-rolled components) |
| Icon library | none (no icons used in Phase 4; Phase 5 needs no icon library -- use Unicode/SVG inline for drawer toggle) |
| Font | Cinzel (display), Inter (body) -- loaded via next/font/google |

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, HP bar internal padding |
| sm | 8px | Compact element spacing, drawer section gaps |
| md | 12px | Inner padding for drawer sections, message card padding |
| lg | 16px | Default element spacing, drawer body padding |
| xl | 24px | Section padding, gap between drawer content groups |
| 2xl | 32px | Layout gaps, drawer header/footer padding |
| 3xl | 48px | Not used in this phase |

Exceptions: Touch target minimum 44px height for drawer toggle button and load-more button (accessibility).

---

## Typography

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Body | 14px | 400 (regular) | 1.5 | Inter |
| Label | 12px | 600 (semibold) | 1.4 | Inter |
| Heading | 18px | 700 (bold) | 1.2 | Cinzel |
| Display | 24px | 700 (bold) | 1.2 | Cinzel |

Usage in this phase:
- **Body (14px):** Chat messages (narrator and player), inventory list items, ability scores
- **Label (12px):** Section headers inside drawer ("ABILITIES", "INVENTORY", "EQUIPMENT"), HP readout in header, "Load earlier messages" button text
- **Heading (18px):** Character name at top of drawer
- **Display (24px):** Not used in this phase (available for consistency)

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #0a0a0a (doom-black) | Page background, chat area background |
| Secondary (30%) | #141414 (doom-dark) / #1a1a1a (doom-card) | Header bar, input bar, drawer background (#141414), drawer sections (#1a1a1a) |
| Accent (10%) | #ffe000 (doom-yellow) | Character sheet toggle button icon, HP bar fill (healthy), drawer section borders, active/hover states |
| Destructive | #8b0000 (doom-blood) | HP bar fill when HP is critically low (at or below 25% max HP) |
| Semantic: danger | #ff1493 (doom-pink) | HP bar fill when HP is low (26-50% max HP), error state text |
| Neutral text | #e8e0d4 (doom-bone) | Body text, inventory items, ability labels |
| Muted text | #8a8a8a (doom-ash) | Secondary labels, disabled states, placeholder text |

Accent reserved for: character sheet toggle button highlight, HP bar healthy fill, drawer section accent borders (left border on section cards), "Load earlier messages" hover state, header HP text when healthy.

### Store Shape Extension

```typescript
interface CharacterData {
  name: string;
  currentHp: number;
  maxHp: number;
  abilities: {
    strength: number;
    agility: number;
    presence: number;
    toughness: number;
  };
  weapon: string | null;
  armor: string | null;
  inventory: string[];
}
```

Added to `SessionState`:
- `characterData: CharacterData | null`
- `drawerOpen: boolean`
- `toggleDrawer: () => void`
- `setCharacterData: (data: CharacterData) => void`

## Interaction Contracts

### Character Drawer

| Property | Value |
|----------|-------|
| Slide direction | Right edge, slides left into view |
| Width | 320px fixed (desktop), 100vw (mobile, below 640px) |
| Animation | 200ms ease-out slide + fade |
| Backdrop | Semi-transparent black overlay (#0a0a0a at 60% opacity), click to close |
| Close trigger | Backdrop click, close button (top-right), Escape key |
| Z-index | z-50 (above header z-40, below grain texture z-50 -- grain is pointer-events:none so no conflict) |
| Scroll | Internal scroll on drawer body; header and close button fixed within drawer |
| Focus trap | Yes -- tab cycles within drawer when open |

### Drawer Layout (top to bottom)

1. **Header row:** Character name (Heading 18px, doom-yellow) + close button (right-aligned)
2. **HP section:** Full-width `HpBar` with "HP 6/8" label overlay
3. **Abilities section:** 2x2 grid of `AbilityScore` components (STR, AGI, PRE, TOU)
4. **Equipment section:** Weapon slot + Armor slot, stacked vertically
5. **Inventory section:** Scrollable list of inventory items

Each section separated by 24px vertical gap. Section cards use doom-card (#1a1a1a) background with 2px left border in doom-yellow.

### Header HP Indicator (CharacterDrawerToggle)

| Property | Value |
|----------|-------|
| Position | Right side of header nav, before Sessions/Logout links |
| Content | Clickable button: Unicode shield character or "HP" label + "6/8" text |
| Text style | Label (12px, semibold), color follows HP threshold logic |
| Click action | Opens/closes CharacterDrawer |
| Visibility | Hidden during `character-creation`, fades in (200ms opacity transition) when status becomes `in-progress` |
| Min touch target | 44px height |

### HP Bar Component

| Property | Value |
|----------|-------|
| Height | 8px in header (mini), 12px in drawer (full) |
| Background | doom-card (#1a1a1a) |
| Fill | Width = (currentHp / maxHp) * 100%, color per HP threshold table |
| Border radius | 4px |
| Transition | Width and color animate over 300ms ease-in-out |
| Label | Overlaid text "HP {current}/{max}" centered, Label typography (12px semibold) -- drawer only |

### Load More Button

| Property | Value |
|----------|-------|
| Position | Top of message list, above oldest visible message |
| Label | "Load earlier messages" |
| Style | Text button (no background), doom-ash text, doom-yellow on hover |
| Loading state | Label changes to "Loading..." with doom-pulse animation |
| Visibility | Hidden when all messages are loaded (totalMessages === messages.length) |
| Messages per page | 20 |

### Gameplay Mode Transition (D-05)

| Property | Value |
|----------|-------|
| Trigger | `state_update` SSE event with `status: "in-progress"` (was `character-creation`) |
| Header change | `CharacterDrawerToggle` fades in over 200ms |
| Input change | Placeholder text switches from "Speak, wretch..." to "What do you do?" |
| Animation | CSS opacity transition on toggle button; no interstitial, no modal, no announcement |
| Narrative | Transition is narrator-driven -- the GM's text describes the shift; UI simply reflects it |

### State Update Handling (D-06, D-07)

| Property | Value |
|----------|-------|
| Source | `state_update` SSE events |
| Update target | `characterData` in sessionStore |
| UI feedback | None (silent). HP bar and drawer content re-render from store. No toasts, no flashes. |
| Initial load | `GET /sessions/{id}` response populates `characterData` from DTO fields |
| Drawer reads | Drawer reads from `useSessionStore(s => s.characterData)` -- no API fetch on open |

## Accessibility Contract

| Requirement | Implementation |
|-------------|----------------|
| Drawer focus trap | Focus cycles within drawer when open; focus returns to toggle button on close |
| Escape to close | Drawer closes on Escape keypress |
| ARIA labels | Drawer toggle: `aria-label="Open character sheet"` / `aria-label="Close character sheet"`; Drawer: `role="dialog"` + `aria-modal="true"` + `aria-label="Character sheet"` |
| HP bar | `role="progressbar"` + `aria-valuenow` + `aria-valuemin="0"` + `aria-valuemax` + `aria-label="Hit points"` |
| Load more | Standard button semantics; `aria-busy="true"` during loading |
| Color contrast | doom-bone (#e8e0d4) on doom-black (#0a0a0a) = 13.5:1 ratio (AAA). doom-yellow (#ffe000) on doom-black = 14.2:1 (AAA). doom-ash (#8a8a8a) on doom-black = 5.9:1 (AA). |

## Responsive Behavior

| Breakpoint | Behavior |
|------------|----------|
| < 640px (mobile) | Drawer takes full viewport width (100vw). Chat max-width removed. Header HP readout shows numeric only ("6/8"), no bar. |
| >= 640px (tablet/desktop) | Drawer is 320px wide, slides from right. Chat maintains max-w-2xl. Header shows mini HP bar + numeric. |

No layout changes to the chat area itself -- it remains full-width single-column at all breakpoints, matching Phase 4.
