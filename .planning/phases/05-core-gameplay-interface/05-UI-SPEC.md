## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, ability score internal spacing |
| sm | 8px | Compact element spacing, HP bar padding, inventory item gaps |
| md | 16px | Default element spacing, drawer section padding, message gaps |
| lg | 24px | Drawer section breaks, header element groups |
| xl | 32px | Drawer outer padding, chat window top/bottom padding |
| 2xl | 48px | Not used this phase |
| 3xl | 64px | Not used this phase |

Exceptions: Touch targets for the character sheet toggle button and drawer close button are 44px minimum (accessibility tap target).

## Typography

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Body | 14px | 400 (regular) | 1.5 | Inter |
| Label | 12px | 400 (regular) | 1.4 | Inter |
| Heading | 18px | 600 (semibold) | 1.2 | Cinzel |
| Display | 24px | 600 (semibold) | 1.2 | Cinzel |

Usage notes:
- **Body (14px):** Chat messages (narrator and player), inventory item descriptions, ability modifier values
- **Label (12px):** "Game Master" attribution, ability labels (STR, AGI, PRE, TOU), section headers in drawer, HP readout in header, "Load earlier messages" button text
- **Heading (18px):** Character name in drawer
- **Display (24px):** Not used in this phase (reserved for future mechanical overlays in Phase 6)

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0a0a0a` doom-black | Page background, chat area background |
| Secondary (30%) | `#1a1a1a` doom-card | Drawer background, narrator message cards, input bar background, header bar |
| Accent (10%) | `#ffe000` doom-yellow | HP bar fill, character sheet toggle button border, drawer section dividers, active send button |
| Destructive | `#8b0000` doom-blood | Low HP warning (HP below 25% of max) |

Accent reserved for:
- HP bar fill color (continuous bar)
- Character sheet toggle button highlight/border on hover
- "Load earlier messages" button text color on hover
- Drawer section divider lines (border-grunge pattern from globals.css)
- Send button background (already established)

Additional semantic colors (from existing palette):
- `#ff1493` doom-pink: Not used this phase (reserved for damage/death in Phase 6)
- `#e8e0d4` doom-bone: Primary text color for body content
- `#8a8a8a` doom-ash: Secondary text, labels, disabled states
- `#141414` doom-dark: Header background, input bar background

## Interaction Contracts

### Character Sheet Drawer (D-01, D-02)

- **Trigger:** Click character sheet toggle button in header (visible only when status is `in-progress`)
- **Animation:** Slide in from right edge, CSS `transform: translateX` with `transition-transform duration-300 ease-in-out`
- **Width:** 320px (`w-80`)
- **Backdrop:** Semi-transparent black overlay (`bg-black/50`), click to dismiss
- **Z-index:** Drawer at z-50, backdrop at z-40
- **Close:** Click backdrop, click X button in drawer header, or press Escape key
- **Content layout (top to bottom):**
  1. Character name (Heading 18px, Cinzel, doom-bone)
  2. HP bar (full width, 8px tall, doom-yellow fill, doom-card track, "HP 6/8" label right-aligned above)
  3. Abilities grid (2x2: STR, AGI, PRE, TOU -- each showing modifier with +/- sign)
  4. Weapon line: weapon kind + damage die (e.g., "Sword -- d6")
  5. Armor line: tier label (e.g., "Medium Armor")
  6. Inventory list (scrollable if long, divider above)
- **Data source:** characterStore (Zustand). No API fetch on open (D-07).

### Header HP Indicator (D-03)

- **Location:** Right side of header, before character sheet toggle button
- **Format:** Compact HP bar (48px wide, 4px tall) with "HP 6/8" text beside it in label typography (12px, doom-bone)
- **Visibility:** Fades in with `transition-opacity duration-500` when session status changes to `in-progress`
- **Color:** Doom-yellow fill. When HP below 25% of max, fill color changes to doom-blood.
- **Update:** Immediate, silent, no animation on value change (D-06)

### Character Sheet Toggle Button

- **Location:** Right side of header, after HP indicator
- **Label:** "CHARACTER" in label typography (12px, uppercase, tracking-wider)
- **Style:** doom-ash text, transparent background. Hover: doom-yellow text. Min tap target: 44px height.
- **Visibility:** Same fade-in as HP indicator (tied to `in-progress` status)

### Load-More Pagination (D-04)

- **Trigger:** "Load earlier messages" button at top of chat message list
- **Visibility:** Only shown when `hasMoreMessages` is true
- **Style:** Centered text button, doom-ash text, doom-card background rounded pill, 12px uppercase label. Hover: doom-yellow text.
- **Loading state:** Text changes to "Loading..." with a subtle pulse animation
- **Behavior:** Fetches next page from `GET /sessions/{id}/messages?page=N`. Prepends older messages. Preserves scroll position using scrollHeight delta technique.
- **Messages per page:** 20

### Gameplay Mode Transition (D-05)

- **Trigger:** Session status changes from `character-creation` to `in-progress` (via SSE state_update)
- **Header changes:** Character sheet button and HP indicator fade in over 500ms (`transition-opacity duration-500`)
- **Input placeholder:** Changes from "Speak, wretch..." to "What do you do?"
- **No interstitial, no toast, no hard break.** Conversation continues naturally.

### State Updates (D-06, D-07)

- **Trigger:** `state_update` SSE events
- **Behavior:** characterStore updates immediately. HP bar and drawer reflect new values on next render frame.
- **No toast, no flash, no popup.** Silent reflection of narrator-described changes.
- **Initial load:** `GET /sessions/{id}/character` populates characterStore on session mount, before any SSE events.

## Responsive Behavior

| Breakpoint | Layout Change |
|------------|--------------|
| All widths | Single-column chat, full width. Drawer overlays at 320px or 100% width if viewport < 400px. |
| < 400px (small mobile) | Drawer takes full viewport width instead of 320px. HP text in header hides, only compact bar remains. |
| >= 400px | Drawer at 320px. Full HP indicator with text + bar. |

## Accessibility

| Concern | Implementation |
|---------|----------------|
| Drawer focus trap | When drawer opens, focus moves to close button. Tab cycles within drawer. On close, focus returns to toggle button. |
| Escape to close | Drawer closes on Escape keypress |
| aria-label on HP bar | `aria-label="Hit points: {current} of {max}"` |
| aria-live on HP indicator | `aria-live="polite"` on header HP text so screen readers announce changes |
| Load more button | Standard button element, no custom role needed |
| Color contrast | doom-bone (#e8e0d4) on doom-black (#0a0a0a) = 13.5:1 ratio (exceeds WCAG AAA). doom-ash (#8a8a8a) on doom-black = 5.9:1 (exceeds WCAG AA). |
