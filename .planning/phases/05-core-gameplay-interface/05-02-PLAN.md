    Create the `src/components/character/` directory. Build four leaf components per the UI-SPEC visual contracts:

    **HpBar.tsx** -- Reusable HP bar with two variants (mini for header, full for drawer).
    Props: `{ currentHp: number; maxHp: number; variant?: "mini" | "full" }`.
    - Mini variant: 8px height, no label. Full variant: 16px height, centered label "HP {current}/{max}" in Label typography (12px bold).
    - Background: `bg-doom-card` (#1a1a1a).
    - Fill width: `(currentHp / maxHp) * 100%` -- use inline style.
    - Fill color per threshold:
      - `> 50%`: `bg-[#ffe000]` (doom-yellow)
      - `26-50%`: `bg-[#ff1493]` (doom-pink)
      - `1-25%`: `bg-[#8b0000]` (doom-blood)
      - `0%`: `bg-[#8a8a8a]` (doom-ash)
    - Border radius: `rounded` (4px).
    - Transition: `transition-all duration-300 ease-in-out` on the fill div for width and color.
    - Accessibility: outer div gets `role="progressbar"`, `aria-valuenow={currentHp}`, `aria-valuemin={0}`, `aria-valuemax={maxHp}`, `aria-label="Hit points"`.
    - Add `"use client";` directive at top.

    **AbilityScore.tsx** -- Single ability display.
    Props: `{ name: string; modifier: number }`.
    - Layout: vertical stack centered. Name in Label typography (12px bold, uppercase, doom-ash). Modifier value in Body typography (14px, doom-bone).
    - Show modifier with explicit sign: `+2`, `-1`, `0` (use `modifier > 0 ? \`+${modifier}\` : \`${modifier}\``).
    - Compact padding: `p-2` inside a `bg-doom-card rounded` container.
    - Add `"use client";` directive at top.

    **EquipmentSlot.tsx** -- Weapon or armor display.
    Props: `{ label: string; value: string | null }`.
    - Layout: horizontal row. Label in Label typography (12px bold, uppercase, doom-ash), value in Body typography (14px, doom-bone). If value is null, show "None" in doom-ash.
    - Container: `flex items-center justify-between py-1`.
    - Add `"use client";` directive at top.

    **InventoryList.tsx** -- Scrollable inventory item list.
    Props: `{ items: string[] }`.
    - If items is empty, show "Empty" in doom-ash italic.
    - Otherwise, render an unordered list (`<ul>`) with each item as `<li>` in Body typography (14px, doom-bone) with `py-0.5` spacing.
    - Container: `max-h-40 overflow-y-auto` for scroll when many items.
    - Add `"use client";` directive at top.
  </action>
