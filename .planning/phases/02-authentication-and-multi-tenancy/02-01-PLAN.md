    2. Update CampaignEntityConfiguration.cs -- configure UserId:
       ```csharp
       builder.Property(e => e.UserId).IsRequired().HasMaxLength(450);
       builder.HasIndex(e => e.UserId);
       ```
       MaxLength 450 matches Identity's default key length. Index enables efficient per-user campaign lookups.

    3. Delete the existing SQLite database file (if present) -- pre-release, no real users. The new migration will contain everything:

       ```
       rm -rf WrtechedWhispers/WretchedWhispers.Infrastructure/Persistence/Migrations/
       ```

    5. Create a fresh combined migration:
       ```
       dotnet ef migrations add InitialCreateWithIdentity --project WrtechedWhispers/WretchedWhispers.Infrastructure --startup-project WrtechedWhispers/WretchedWhispers.Infrastructure
       ```
       This produces a single migration containing: all 5 existing game tables, 4 Identity tables (AspNetUsers, AspNetUserClaims, AspNetUserLogins, AspNetUserTokens), and CampaignEntity.UserId column with index.
