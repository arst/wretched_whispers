# Phase 6 — UI Design Contract

> Visual and interaction contract for Mechanical Visibility and Session Lifecycle. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Misery pip gaps, icon badge internal padding, inline gaps |

## Component Inventory

### New Components

#### 1. MiseryTracker
- **Location**: `src/components/character/MiseryTracker.tsx`
- **Rendered in**: `CharacterDrawerToggle` (header area), next to existing HP indicator
- **Props**: `count: number` (0-7)
- **Visual**: 7 circular pips in a horizontal row, 8px diameter each, 4px gap between pips
- **Filled pip**: `bg-doom-pink` solid circle
- **Empty pip**: `bg-doom-ash/40` dim circle
- **Pulse**: When `count` increases, the newly filled pip plays `doom-pulse` keyframe animation (0.6s ease-in-out). Track previous count via `useRef` to prevent re-animation on re-render. Remove animation class via `onAnimationEnd` callback.
- **Accessibility**: `aria-label="Misery tracker: {count} of 7"` on container, `role="img"`
- **Visibility**: Only visible when `status === "in-progress"` (same condition as HP indicator)

#### 2. InjuryBadges
- **Location**: `src/components/character/InjuryBadges.tsx`
- **Rendered in**: `CharacterDrawer` as new "INJURIES" section between HP and Abilities
- **Props**: Individual boolean flags from `CharacterData`
- **Visual**: Grid of small badges (2 columns). Each badge is a text glyph + short label. Only active injuries are shown; inactive injuries are hidden entirely (not dimmed).
- **Injury glyphs** (Unicode text, no external icons):
  - Lost Eye: `\u2298` (circled division) + "LOST EYE"
  - Stabbed Lung: `\u2620` (skull and crossbones) + "STABBED LUNG"
  - Broken Hand: `\u270B` (raised hand) + "BROKEN HAND"
  - Crushed Foot: `\u2B24` (black circle) + "CRUSHED FOOT"
  - Severed Arm: `\u2702` (scissors) + "SEVERED ARM"
  - Smashed Face: `\u2717` (ballot X) + "SMASHED FACE"
- **Badge styling**: `text-doom-pink text-xs font-bold uppercase tracking-wider` for label, glyph in `text-doom-pink text-sm`
- **Empty state**: If no injuries, section is not rendered at all
- **Section header**: "INJURIES" in `text-xs font-bold uppercase text-doom-ash` (matches existing section headers)

#### 3. StatusIndicators
- **Location**: `src/components/character/StatusIndicators.tsx`
- **Rendered in**: `CharacterDrawer` as new "STATUS" section after Injuries
- **Props**: `isInfected: boolean`, `isDizzyFromMagic: boolean`, `isEncumbered: boolean`
- **Visual**: Vertical list of active status effects. Only active statuses shown.
  - Infected: `\u2623` (biohazard) + "INFECTED" in `text-doom-pink`
  - Dizzy from Magic: `\u2728` (sparkles) + "ARCANE DAZE" in `text-doom-yellow`
  - Encumbered: `\u2693` (anchor) + "ENCUMBERED" in `text-doom-ash`
- **Empty state**: Section not rendered if no active statuses
- **Section header**: "STATUS" in same style as INJURIES header

#### 4. EndCard
- **Location**: `src/components/session/EndCard.tsx`
- **Rendered in**: `GameSessionPage` (`sessions/[id]/page.tsx`), overlaid on chat area
- **Trigger**: Show only when `status === "ended"` AND `isStreaming === false` (wait for narrator to finish)
- **Props**: `characterName: string`, `isDead: boolean`, `worldEnded: boolean`, `miseryCount: number`, `currentDay: number`, `onRestart: () => void`
- **Layout**: Centered panel over a `bg-doom-black/80` backdrop, max-width 400px
- **Death variant** (`isDead && !worldEnded`):
  - Title: "YOUR WRETCH HAS FALLEN" in `font-display text-2xl font-bold text-doom-pink uppercase tracking-widest`
  - Accent border: `border-doom-pink`
- **Apocalypse variant** (`worldEnded`):
  - Title: "THE WORLD HAS ENDED" in `font-display text-2xl font-bold text-doom-yellow uppercase tracking-widest`
  - Accent border: `border-doom-yellow`
- **Priority**: If both `isDead` and `worldEnded` are true, show apocalypse variant (world ending trumps individual death)
- **Content**:
  - Character name in `font-display text-lg text-doom-bone`
  - Stats row: "Day {currentDay}" and "{miseryCount} Miseries Witnessed" in `text-xs text-doom-ash uppercase tracking-wider`
  - Divider: `border-t border-doom-card` with 16px vertical margin
  - "BEGIN ANEW" button: Full width, 44px min-height, `font-display text-sm font-bold uppercase tracking-widest`, background uses accent color (pink for death, yellow for apocalypse), text is `doom-black`
- **Animation**: Fade in with `opacity 0->1` over 600ms, panel slides up 16px with `transform` over 600ms. Use CSS transition triggered by a mounted state.
- **Accessibility**: `role="dialog"`, `aria-modal="true"`, `aria-label="Game over"`, focus trapped to "BEGIN ANEW" button

### Extended Components

#### 5. ToolResultCallout (enriched dice display)
- **File**: `src/components/chat/ToolResultCallout.tsx` (existing)
- **Change**: When `isDice === true` and `toolResult.result` is a structured `DiceRollData` object (has `formula` and `result` fields), render enriched layout instead of plain text.
- **Enriched layout**:
  - "FATE DECIDES" header: unchanged (`text-doom-yellow text-xs font-bold uppercase tracking-wider`)
  - Formula line: `{formula}` in `text-doom-ash text-xs font-mono` (e.g., "d20+2")
  - Result line: `= {result}` in `text-doom-yellow font-bold text-lg font-display` (large, prominent number)
  - Layout: Stacked vertically (formula above result) within existing `border border-doom-yellow/60 bg-doom-dark rounded px-3 py-2` container
- **Fallback**: If `result` is not a structured object (plain number/string), keep existing rendering. This ensures backward compatibility with older messages.
- **Type guard**: `isDiceRollData(result: unknown): result is DiceRollData` checks for `typeof result === "object" && result !== null && "formula" in result && "result" in result`

#### 6. CharacterDrawer (new sections)
- **File**: `src/components/character/CharacterDrawer.tsx` (existing)
- **Change**: Add `InjuryBadges` section between HP and Abilities. Add `StatusIndicators` section between Abilities and Equipment.
- **Section order**: HP -> Injuries -> Status -> Abilities -> Equipment (armor tier + shield) -> Inventory
- **Conditional rendering**: Injury and Status sections only appear when at least one flag is active

#### 7. EquipmentSlot (armor tier + shield condition)
- **File**: `src/components/character/EquipmentSlot.tsx` (existing)
- **Change**: Accept optional `tier` and `isBroken` props
- **Armor display**: When `tier` is provided, show tier label after armor name: "Heavy Armor" -> "Heavy Armor" with a tier indicator. Tier indicator: 1-3 small filled squares (Light=1, Medium=2, Heavy=3) in `text-doom-yellow`, displayed inline after the value text.
  - Light: `\u25A0` (1 square)
  - Medium: `\u25A0\u25A0` (2 squares)
  - Heavy: `\u25A0\u25A0\u25A0` (3 squares)
  - NoArmor: no indicator shown
- **Shield row**: New `EquipmentSlot` with `label="SHIELD"` added in CharacterDrawer when `hasShield === true`. When `isShieldBroken === true`, value text gets `line-through text-doom-ash` styling.

#### 8. CharacterDrawerToggle (add MiseryTracker)
- **File**: `src/components/character/CharacterDrawerToggle.tsx` (existing)
- **Change**: Render `MiseryTracker` component inline, between HP indicator and the button boundary. MiseryTracker reads `miseryCount` from Zustand store.
- **Layout**: `flex items-center gap-2` — HP text, HP bar, then MiseryTracker pips. On mobile (< sm), HP bar is hidden but MiseryTracker remains visible.

#### 9. SessionCard (ended session indicator)
- **File**: `src/components/session/SessionCard.tsx` (existing)
- **Change**: When `status === "ended"`, add a skull glyph `\u2620` before the status label text. Change status label from "Ended" to "\u2620 Fallen" (or "\u2620 Doomed" if we can distinguish -- but since SessionPreviewDto only has status string, use "\u2620 Ended" generically).
- **Visual**: The pink border styling already exists for ended status. Add `opacity-75` to the entire card to visually de-emphasize ended sessions.

#### 10. ChatInput (read-only for ended sessions)
- **File**: `src/components/chat/ChatInput.tsx` (existing)
- **Change**: Accept `disabled` prop (or check `status === "ended"` from store). When disabled: input gets `bg-doom-card cursor-not-allowed` styling, placeholder text changes to "This tale has ended...", submit button hidden.

#### 11. GameSessionPage (end card integration + read-only mode)
- **File**: `src/app/sessions/[id]/page.tsx` (existing)
- **Change**: When `status === "ended"` and `isStreaming === false`, render `EndCard` overlay. "Begin Anew" handler: call `POST /sessions`, navigate to new session URL.

## Interaction Contracts

### Misery Pip Pulse
- **Trigger**: `miseryCount` in Zustand store increases from previous value
- **Animation**: `doom-pulse` keyframe (already in globals.css): `0%,100% { opacity: 0.3 } 50% { opacity: 1 }`, duration 0.6s, ease-in-out
- **Scope**: Only the newly filled pip pulses, not all filled pips
- **Implementation**: `useRef` tracks previous count. `useEffect` compares current vs previous. Apply animation class, remove via `onAnimationEnd`.

### End Card Appearance
- **Trigger**: `status === "ended" && isStreaming === false`
- **Delay**: 0ms after conditions met (narrator text already finished)
- **Animation**: Backdrop fades in over 400ms (`opacity 0 -> 0.8`). Panel fades in over 600ms with 200ms delay, slides up 16px to final position.
- **Focus**: After animation, focus moves to "BEGIN ANEW" button

### "Begin Anew" Flow
1. User clicks "BEGIN ANEW"
2. Button shows loading state (text changes to "SUMMONING..." + `animate-pulse`)
3. `POST /sessions` creates new session
4. On success: `router.push(/sessions/{newId})` navigates to new session
5. On failure: Show inline error text below button: "The fates resist. Try again."

### Ended Session Read-Only
- Chat history fully scrollable
- ChatInput disabled with placeholder "This tale has ended..."
- End card overlay shown (same as when game ended live)
- Character drawer still openable (shows final state)
