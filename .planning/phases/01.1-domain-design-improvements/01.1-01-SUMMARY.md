## Decisions Made
- **Penalty model split:** The existing Character.Challenge code uses two different penalty mechanisms: fixed DR increases (SeveredArm +4, BrokenHand +2, StabbedLung/CrushedFoot +2) and dice-based penalties (SmashedFace D4, LostEye D4). Rather than forcing all penalties into a single int return type, InjurySet provides `GetStrengthPenalty()`/`GetAgilityPenalty()` returning ints for fixed penalties, and `GetPresencePenaltyDice()`/`GetAgilityPenaltyDice()` returning DiceExpr for dice-based penalties. This accurately models the existing code and avoids lossy abstraction.
- **SeveredArm dominates BrokenHand:** The existing code has `when HasSeveredArm` as a separate case before `when HasBrokenHand`, meaning SeveredArm's +4 takes precedence over BrokenHand's +2. InjurySet.GetStrengthPenalty() returns max(4,2)=4 when both are present, matching this behavior.
- **DiceExpr.Zero:** Added as a canonical representation for "no dice to roll", used by penalty dice methods to avoid nullable returns.
- **JsonInclude on Encounter setters:** Added [JsonInclude] attribute when changing IsStarted/IsEnded to private set, ensuring System.Text.Json can still deserialize these properties.
