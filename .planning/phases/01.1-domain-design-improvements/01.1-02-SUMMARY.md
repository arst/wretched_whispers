## Decisions Made
- **Inventory.InventoryItems type:** Kept as `List<InventoryItem>` return type rather than `IReadOnlyList<InventoryItem>` because STJ constructor parameter binding requires the property type to match the constructor parameter type. The backing field is `private readonly List<InventoryItem>`, providing internal encapsulation. The plan's `IReadOnlyList` suggestion was adapted for STJ compatibility.
- **Abilities immutability approach:** Changed all four ability properties from `{ get; private set; }` with `[JsonInclude]` to simple `{ get; }` (truly immutable). STJ binds via the `[JsonConstructor]` parameters. `ModifyAbility` returns a new `Abilities` instance.
- **ArmorTier.RollDamageReduction location:** Placed on abstract base class, not on subtypes, since the base method uses the polymorphic `DamageReduction` property that each subtype already overrides.
- **Character.Abilities setter:** Changed from `{ get; }` to `{ get; private set; }` with `[JsonInclude]` to support `Abilities = Abilities.ModifyAbility(kind, delta)` reassignment in Improve/Degrade.
