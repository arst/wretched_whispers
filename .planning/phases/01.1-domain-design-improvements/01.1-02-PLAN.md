<objective>
Refactor Character's internals: migrate 7 boolean injury flags to InjurySet, move armor reduction to ArmorTier strategy, convert Inventory from record to sealed class, make Abilities immutable, and update broken-state resolution. All changes preserve Character's existing public API surface.

Purpose: Eliminate the god-class smell by distributing behavior to proper locations (ArmorTier for armor reduction, InjurySet for penalties, Inventory for collection encapsulation) while keeping Character as the orchestrating aggregate root with the same external contract.
Output: Character.cs significantly simplified, with behavior properly distributed to ArmorTier, InjurySet, Inventory, and Abilities types.
</objective>
