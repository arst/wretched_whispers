<objective>
Fix three cross-phase integration gaps: (1) SaveCampaign preserves tenant ownership during agent turns via scoped ITenantContext, (2) API auto-creates database on first launch via MigrateAsync, (3) console apps use ITenantContext for consistency.

Purpose: Without this fix, all 10 parameterless SaveCampaign call sites in CampaignPlugin and CampaignService silently strip UserId from campaigns, breaking session listing (SESS-02), session resume (SESS-03), and auto-save (SESS-04). Fresh API deploys fail with missing database (INFR-02). Multi-tenant isolation is broken after any agent turn (INFR-03).

Output: ITenantContext interface + implementation, updated ICampaignsRepository interface, updated repository, endpoint filter, API migration startup, console app tenant setup, updated tests, integration test for full plugin-level tenant preservation through scoped DI.
</objective>
