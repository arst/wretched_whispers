## Decisions Made
- ITenantContext registered as Scoped in web API (one instance per request) and Singleton in console apps (one user for entire process lifetime)
- Endpoint filter chosen over middleware for tenant setup (more targeted, only runs for session endpoints)
- Test factories delegate schema creation to Program.cs MigrateAsync instead of using separate BuildServiceProvider + EnsureCreated calls
- SqliteCampaignsRepository converted to primary constructor pattern (project convention for services)

### Auto-fixed Issues

**1. [Rule 1 - Bug] Test factories EnsureCreated conflicted with MigrateAsync**
- **Found during:** Task 2 (integration tests)
- **Issue:** Adding MigrateAsync to Program.cs caused all WebApplicationFactory-based tests (19 tests across 3 test classes) to fail because the factories' EnsureCreated created the schema without migration history, causing MigrateAsync to fail when the app started
- **Fix:** Removed BuildServiceProvider + EnsureCreated blocks from all 3 test factories (SessionWebAppFactory, AuthWebAppFactory, StreamingWebAppFactory), letting Program.cs MigrateAsync handle schema creation for test databases
- **Files modified:** SessionEndpointTests.cs, AuthEndpointTests.cs, SessionStreamingTests.cs
