    2. Create `Endpoints/SessionEndpoints.cs` as a static class with `MapSessionEndpoints(this WebApplication app)`:

       **POST /sessions** (SESS-01):
       - Requires authorization
       - Extract userId from `HttpContext.User.FindFirstValue(ClaimTypes.NameIdentifier)`
       - Create a new Campaign via `Campaign.Create(DiceExpr.Parse("d6"), "New Campaign", "A new journey into doom")` -- the GM will customize these conversationally via tool calls in the first interaction
       - Save campaign with userId: `await campaignsRepo.SaveCampaign(campaign, userId)`
       - Create a chat session: `await chatHistoryRepo.CreateSession(campaign.Id)`
       - Return `Results.Created($"/sessions/{campaign.Id}", new CreateSessionResponse(campaign.Id, campaign.Id))`
       - Note: Session ID = Campaign ID (1:1 mapping per locked decision)

       **GET /sessions** (SESS-02):
       - Requires authorization
       - Extract userId, load campaigns via `campaignsRepo.GetForUser(userId)`
       - For each campaign, load the first character (if any) via `charactersRepo.Get(campaign.Players.FirstOrDefault())` to populate character name/HP
       - Load last chat session timestamp by getting sessions for campaign and checking most recent
       - Derive status: no characters = "character-creation", IsActive = "in-progress", IsEnded = "ended"
       - Return `Results.Ok(previews)` as `List<SessionPreviewDto>`

       **GET /sessions/{sessionId}** (SESS-03):
       - Requires authorization
       - Extract userId, load campaign by sessionId (since session=campaign), verify `campaign != null`
       - Verify campaign belongs to user: load campaigns for user and check if sessionId is in the list. If not, return `Results.NotFound()`
       - Get chat sessions for campaign, load the first (or only) chat session
       - Load chat history with pagination: read query params `?page=1&pageSize=50` (default 50 per discretion recommendation)
       - Build `SessionDetailDto` with campaign state + paginated messages
       - Return `Results.Ok(detail)`

       **GET /sessions/{sessionId}/messages** (pagination for older messages):
       - Requires authorization
       - Same ownership verification as above
       - Accept `?page=1&pageSize=50`
       - Load full chat history, compute pagination manually (offset = (page-1)*pageSize, take pageSize)
       - Return paginated `ChatMessageDto` list with total count

       DI parameters for each endpoint: inject `ICampaignsRepository`, `ICharactersRepository`, `IChatHistoryRepository` as handler parameters (Minimal API auto-resolves from DI). Use `System.Security.Claims.ClaimTypes.NameIdentifier` for userId.

    3. Wire in Program.cs: Add `app.MapSessionEndpoints();` after the existing `app.MapGet("/auth/me", ...)` line. Add the using for `WretchedWhispers.Api.Endpoints`.
